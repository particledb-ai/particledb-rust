# tests - Rust SDK integration tests

| File | What it is for |
|---|---|
| `integration.rs` | Full-feature tests over the PG wire (`postgres` crate); `#[ignore]`d, configured by `PARTICLEDB_TEST_*`. Run with `cargo test --test integration -- --ignored --test-threads=1`. |
| `native_wire_live.rs` | LIVE native-wire tests (need `PDB_NATIVE_PORT`, a `--no-auth` server; else `SKIP`): every PDB type round-trips (literal and parameter writes, simple and prepared reads, typed `WHERE col = $1` probes), parameter binding (injection string stored verbatim, count mismatch refused, re-prepare after `DISCARD ALL`), a 100 000-row `execute_many_in_transaction` plus a two-frame autocommit `execute_many` with count/sum/per-row invariants, per-row failure reporting, SQLSTATEs on the simple and prepared paths. Each test prints `NWL_PASS <name>`. |
| `native_wire_auth.rs` | LIVE: the HELLO/AUTH handshake against a server that requires a password (`PDB_AUTH_PORT`/`USER`/`PASS`); a wrong password is `28P01`. Prints `NWA_PASS`. |
| `readiness.rs` | Config validation and credential redaction (no server). LIVE parts, which return early unless `PDB_NATIVE_PORT` (a `--no-auth` server) is set: transaction commit and rollback, pool-size limits and timed-out waiters, KV and public helper SQL. TLS verification needs `PDB_TLS_PORT` and `PDB_TLS_CA`. |
| `run_live.sh` | Starts a server (`$PARTICLEDB_BIN`, else `particledb` on PATH) with `--no-auth` and a second one requiring scram-sha-256 auth (fresh data dirs, random port block), runs `native_wire_live`, `native_batch_errors` and `native_wire_auth`, and fails unless every marker printed. |
| `sabotage_live.sh` | Proves the live tests can fail: an unmutated copy must pass, then each of seven single-edit mutations (rows dropped, params ignored, decimal scale, vector byte order, bulk sends one chunk, SQLSTATE lost, failed rows hidden) is applied to a COPY of the crate and its named test must fail (a mutation that no longer applies, or that does not compile, is red). The working tree is never edited. |
| `unix_socket.rs` | Unix-socket selection: `is_local_host` literals, `unix_socket_path_in`, `Config` defaults. LIVE part (`PDB_NATIVE_PORT`, else `SKIP`): a port with no TCP listener whose `<dir>/.s.PDB.<port>` symlinks the live server's socket answers on `127.0.0.1` / `localhost` / `::1` and fails with `prefer_unix_socket = false` or another dir; a stale socket file in front of the live port falls back to TCP. Prints `NUS_PASS rust`. |
| `ambiguous_failures.rs` | Real-TCP fake server counting requests and accepts (it answers the connect-time HELLO and does not count it): a batch, statement, KV_SET or PING whose connection drops after the request was read returns `Error::Connection`, was received exactly once, and the next call opens a NEW socket (the dead one is not pooled). No ParticleDB server. |
| `native_batch_errors.rs` | LIVE native-wire test: a failed statement in `PdbWireExecutor::execute_batch` (plain batch and `BEGIN ... COMMIT` batch) is returned as `Err`, the pooled connection is not left in a failed transaction, and successful batches/transactions still succeed. Returns early with a `SKIP` line unless `PDB_NATIVE_PORT` is set (127.0.0.1, `--no-auth` server); prints `NBE_PASS rust` when it ran and passed. Run with `PDB_NATIVE_PORT=<port> cargo test --test native_batch_errors -- --nocapture`. |
